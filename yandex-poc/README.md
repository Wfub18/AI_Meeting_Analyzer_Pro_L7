# PoC импорта из Яндекс Диска

Яндекс Диск — выбранный облачный провайдер Pro. PoC использует публичную ссылку и Node.js 24. Для проверки скачанного видео нужен FFprobe. Доступ к личным файлам и папкам Диска не требуется.

## Как получить тестовую ссылку

1. Войдите в свой Яндекс Диск и загрузите короткий учебный MP4 с видео и аудио. Предел — 50 000 000 байт и 300 секунд.
2. В меню файла выберите **Поделиться → Скопировать**. Оставьте доступ по ссылке без пароля и разрешите скачивание.
3. Сохраните ссылку для согласованного сетевого теста. Можно проверить в приватном окне браузера, что ссылка открывает именно файл и показывает кнопку скачивания. [Справка Яндекс Диска](https://yandex.ru/support/yandex-360/customers/disk/web/ru/share/sharing.html)

## Проверки

Офлайн-тесты подставляют ответы HTTP и FFprobe. Команда из корня Pro:

```powershell
node --test --test-isolation=none yandex-poc/import.test.mjs
```

После отдельного согласования сетевого теста укажите путь к установленному FFprobe и передайте полную публичную ссылку:

```powershell
$env:POC_FFPROBE_PATH = (Get-Command ffprobe -CommandType Application -ErrorAction Stop | Select-Object -First 1).Source
$link = Read-Host 'Публичная ссылка Яндекс Диска'
node yandex-poc/import.mjs $link
```

Команда запрашивает метаданные у `/v1/disk/public/resources`, получает временный `href` у `/v1/disk/public/resources/download` и скачивает файл потоком. На эти операции вместе отведено 60 секунд. Результат содержит имя, число байтов, длительность и вычисленный SHA-256. FFprobe проверяет содержимое, дорожки и длительность. Файл удаляется после проверки. [Пример скачивания по публичной ссылке у Яндекса](https://yandex.cloud/ru/docs/datasphere/operations/data/connect-to-ya-disk#upload-file)

Скачивание разрешено по HTTPS через точные хосты `downloader.disk.yandex.ru` и `downloader.dst.yandex.ru` с путём `/disk/…`, а также `mds.storage.yandex.net` с путём `/rdisk/…`. Каждый переход проверяется отдельно, максимум три перенаправления. Транспорт передаёт проверенный публичный IPv4 напрямую в сокет и проверяет TLS-сертификат для имени хоста. Если адрес не проходит проверку, PoC останавливается. Первый сетевой тест подтвердил перенаправление на MDS по имени хоста. Фактический путь и скачивание предстоит проверить повторной согласованной попыткой. Бесплатные публичные ссылки могут временно исчерпать лимит скачиваний. [Ограничения публичных ссылок](https://yandex.ru/support/yandex-360/customers/disk/web/ru/share/sharing.html)
